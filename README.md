
# Introduction to 8086 Assembly Language

The Intel 8086 is a 16-bit microprocessor introduced in 1978 and is one of the most important processors in computer architecture. Assembly language for the 8086 provides a low-level programming interface that allows direct communication with the hardware through machine instructions.

8086 Assembly Language uses mnemonic codes such as `MOV`, `ADD`, `SUB`, and `INT` to represent machine operations. It enables programmers to efficiently control memory, registers, input/output devices, and processor resources.

The 8086 microprocessor contains 16-bit registers, a 20-bit address bus capable of accessing up to 1 MB of memory, and supports both arithmetic and logical operations. Assembly language programming is widely used for understanding computer organization, embedded systems, operating systems, and hardware-level programming.

Studying 8086 Assembly Language helps students understand how software interacts with hardware and provides a strong foundation for learning modern computer architecture and low-level programming concepts.

# Interrupts in Microprocessors

An interrupt is a signal that temporarily stops the normal execution of a program and transfers control to a special routine called an Interrupt Service Routine (ISR). Interrupts allow a microprocessor to respond quickly to events such as keyboard input, timer signals, hardware requests, or software-generated requests.

When an interrupt occurs, the microprocessor saves the current state of the program, executes the corresponding ISR, and then returns to the interrupted program. This mechanism improves system efficiency by enabling the processor to handle important tasks immediately without continuously checking for events.

Interrupts can be classified into two main types: **Hardware Interrupts** and **Software Interrupts**. Hardware interrupts are generated by external devices, while software interrupts are generated by instructions within a program. In the 8086 microprocessor, interrupts are identified by interrupt numbers ranging from **00h to FFh**, providing a total of **256 interrupt types**.

Interrupts play a vital role in computer systems by improving responsiveness, supporting multitasking, and enabling efficient communication between hardware and software.
